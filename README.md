這是一款 Roguelite 回合遊戲

🎮 控制方法
遊戲主要透過 滑鼠 進行操作
在你的回合中，拉動我方單位
放開左鍵 即可將單位射出，拉動力道與距離成正比。
UI 互動：
右上角 Setting：調整遊戲音量（包含主音量與 SFX 音效）與畫面設定。
左側面板：查看隊伍成員狀態、技能冷卻以及當前持有的資源。
裝備操作：將場上的裝備拖入左側的ui中就可以完成裝備。

屬性設計與裝備系統上參考了Buriedbornes
遊戲中會掉落的裝備上會有隨機生成的詞條。

技能：每個單位擁有獨特的觸發技能。請在遊戲中查看。
